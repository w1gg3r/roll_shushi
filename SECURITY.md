# SECURITY BASELINE

- Секреты только в environment/secret manager; реальные `.env` не коммитить.
- Собирать только необходимые персональные данные; определить основания, сроки хранения, роли и обработчиков до запуска.
- Учитывать локализацию баз ПДн граждан РФ.
- Авторизация и RBAC проверяются на сервере; admin закрыт по умолчанию.
- Для директора предусмотреть MFA, аудит и подтверждение критических действий.
- Пароли хешировать современным алгоритмом с индивидуальной солью.
- Сервер рассчитывает цену; webhook проверять и обрабатывать идемпотентно.
- Не хранить PAN/CVV.
- До production провести threat review, тесты прав, secret/dependency scanning и backup/restore.
