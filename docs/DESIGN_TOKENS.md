# Дизайн-токены и фирменный персонаж

Источник: утверждённый основной дизайн «ВОТ ЭТО РОЛЛ» (макет на холсте, версия от 24.11.2026). Токены в `apps/web/src/styles.css` должны совпадать с этим документом.

## Палитра

| Токен | Значение | Использование |
|---|---|---|
| `--orange` | #FF6B00 | Акцент: кнопки, брызги, лосось, нижние полосы карточек |
| `--ink` | #1F1F1F | Логотип, тёмные блоки, основной текст |
| `--cream` | #F7F5ED | Фон страниц, светлые поверхности |
| `--grey` | #A7A7A7 | Декор, иконки; текст на светлом фоне не использовать |
| `--ink-2` | #4A4A4A | Вторичный текст (контраст не ниже 4,5:1 на кремовом фоне) |

Дополнительно: `--white` #FFFFFF для карточек, `--line` #E4E0D3 для разделителей, `--err` #8A1C12 для ошибок. Эти цвета не из утверждённой палитры, а служебные; их утверждение нужно отдельно.

## Типографика

- Заголовки и логотип: Unbounded, 700/900.
- Интерфейс: Golos Text, 400/600/700/800.
- Слоган «Вот это действительно вкусно!»: Golos Text, курсив.
- Шрифты в макете не указаны; выбор Unbounded и Golos Text — предложение, не утверждено директором.

## Персонаж

Ролл-улыбка: чёрный нори, оранжевый лосось сверху, белый рис с лицом (закрытые глаза-дуги, румяные щёки, улыбка), поднятые большие пальцы, оранжевые штрихи вокруг головы. Компонент: `apps/web/src/components/Mascot.tsx`. Декоративный по умолчанию; с подписью `title` становится изображением для скринридера.

## Адаптивность

Точки перехода: 860 px (сетка героя и карточек переходит в один столбец). Минимальные отступы страницы 24 px.

## Доступность

- Видимый фокус: чёрная рамка 3 px с отступом.
- Анимации отключаются при системной настройке «уменьшить движение».
- Касание не меньше 44 px для интерактивных элементов (учитывать при добавлении кнопок).
