# Юридическая карта проекта

## Фактическая модель
ИП — продавец/оператор; собственная кухня; собственная доставка; прямые заказы через собственный сайт/PWA; старт — Вологда, Россия.

## Публичные документы — план
Политика обработки ПДн; отдельные согласия там, где основание — согласие; пользовательские условия; публичная оферта; сведения о продавце; условия оплаты/доставки; отмена/возвраты/претензии; маркетинговое согласие при необходимости; сведения о блюдах, составе и аллергенах.

## Внутренний compliance — план
Положение о ПДн; реестр целей/оснований/сроков; управление доступом; реагирование на инциденты; производственный контроль и процедуры ХАССП; технологические карты; инструкции по хранению, упаковке и доставке.

## Условия подготовки
Не публиковать юридические тексты как готовые до получения реквизитов ИП, адреса кухни, реальных процессов и списка провайдеров. Перед запуском — проверка профильным юристом и специалистом по пищевой безопасности. Проверить актуальные редакции 152-ФЗ, 54-ФЗ, защиты прав потребителей, правил дистанционной продажи (на дату подготовки — ПП РФ №657) и санитарных правил.
