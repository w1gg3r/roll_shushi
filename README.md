# ВОТ ЭТО РОЛЛ

Собственный сервис доставки суши и роллов. Стартовый город — Вологда, Россия; далее предусмотрено масштабирование.

## Бизнес-модель
- Собственная кухня и приготовление.
- Прямые заказы через собственный адаптивный веб-сервис/PWA.
- Собственная доставка.
- Продавец/оператор — действующее ИП; реквизиты не публикуются в репозитории.

## Бренд
Рабочее название: **ВОТ ЭТО РОЛЛ**. Городской бренд с юмором, но без детской стилистики. Фирменный персонаж — центральный элемент; его дизайн и логотип пока в разработке.

Рабочая палитра исходной концепции: оранжевый `#FF6B00`, графит `#1F1F1F`, молочный `#F7F5ED`, серый `#A7A7A7`. Палитра предварительная.

## Технологии
React + TypeScript + Vite; NestJS + TypeScript; REST API; PostgreSQL + Prisma; целевая платформа — Render. Архитектура — модульный монолит.
