# ВОТ ЭТО РОЛЛ

Собственный сервис доставки суши и роллов. Стартовый рынок — Вологда, Россия; архитектура предусматривает дальнейшее масштабирование на другие города.

## Статус проекта

Проект создаётся с нуля. Репозиторий ранее был пуст. На текущем этапе фиксируются продуктовые решения, архитектура и начальная техническая основа.

## Бизнес-модель

- Собственная кухня и приготовление продукции.
- Продажа напрямую конечным покупателям через собственный адаптивный веб-сервис/PWA.
- Собственная доставка.
- Один стартовый город — Вологда; дальнейшее расширение по городам.
- Юридический оператор и продавец — действующее ИП (реквизиты не публикуются в репозитории).

## Бренд

Рабочее название: **ВОТ ЭТО РОЛЛ**.

Утверждённое направление: городской бренд с юмором, но без детской стилистики. Фирменный персонаж — центральный элемент бренда. Его конкретный дизайн, логотип и окончательная айдентика находятся в разработке.

Рабочая палитра исходной концепции:
- Оранжевый: `#FF6B00`
- Графит: `#1F1F1F`
- Молочный: `#F7F5ED`
- Серый: `#A7A7A7`

Палитра и визуальное направление остаются рабочими до сравнительного утверждения дизайна.

## Технологическое направление

Предварительная основа:
- Frontend: React + TypeScript + Vite, адаптивный интерфейс с PWA-ready подходом.
- Backend: Node.js + NestJS + TypeScript, модульный монолит.
- API: REST, версионирование.
- Database: PostgreSQL.
- ORM: Prisma.
- Hosting target: Render.
- Repository: private GitHub repository.

Стек зафиксирован как стартовая техническая гипотеза и может уточняться по результатам реализации и проверок.

## Структура

- `apps/web` — клиентское веб-приложение.
- `apps/api` — backend API.
- `packages/shared` — общие типы и контракты.
- `docs/` — архитектура, решения, бренд и юридическая карта.
- `infra/` — инфраструктурные шаблоны и конфигурация без секретов.

Не коммитить реальные секреты, токены, пароли, ключи, персональные данные, production-конфигурации и реальные реквизиты. Использовать только переменные окружения и безопасные шаблоны.
