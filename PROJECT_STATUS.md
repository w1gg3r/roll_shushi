# PROJECT STATUS

**Дата:** 2026-11-24. **Фаза:** 1 — инженерная основа и проверка каркаса.

## Подтверждено
- Собственная кухня, собственная доставка, прямые заказы через собственный сервис.
- Старт — Вологда, затем масштабирование по городам.
- Продавец/оператор — действующее ИП; реквизиты и налоговый режим уточняются.
- Рабочее название — «ВОТ ЭТО РОЛЛ».
- Характер бренда: юмор без детскости; персонаж — центральный элемент.

## Добавлено в репозиторий
- Документы проекта, архитектура, решения, безопасность, бренд-платформа и юридический чек-лист.
- npm workspaces; React 19 + TypeScript + Vite frontend.
- NestJS API с базовым endpoint `/api/v1/health`.
- Общие типы в `packages/shared`.
- Начальная Prisma-схема: City, Category, Product, ProductVariant.
- Node.js runtime зафиксирован на 22-й ветке через `.nvmrc` и `engines`.
- GitHub Actions workflow `.github/workflows/ci.yml`: установка зависимостей, Prisma validate/generate, typecheck и build.
