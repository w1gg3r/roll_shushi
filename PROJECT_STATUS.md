# PROJECT STATUS

**Дата:** 2026-11-24. **Фаза:** 1 — начальный каркас репозитория.

## Подтверждено
- Собственная кухня, собственная доставка, прямые заказы через собственный сервис.
- Старт — Вологда, затем масштабирование по городам.
- Продавец/оператор — действующее ИП; реквизиты и налоговый режим уточняются.
- Рабочее название — «ВОТ ЭТО РОЛЛ».
- Характер бренда: юмор без детскости; персонаж — центральный элемент.
- Логотип и внешний вид персонажа ещё не утверждены.

## Добавлено в репозиторий
- Документы: README, план, статус, архитектура, решения, безопасность.
- Бренд-платформа и четыре направления визуального сравнения.
- Юридическая карта и чек-лист запуска.
- npm workspaces; React + TypeScript + Vite frontend.
- NestJS API с базовым health endpoint.
- Общие типы.
- Начальная Prisma-схема для городов, категорий, товаров и вариантов.
- .gitignore и .env.example без реальных секретов.

## Не проверено
Инструменты GitHub подтвердили наличие файлов в main, но сборка, typecheck, запуск API/web и валидация Prisma ещё не выполнялись в реальной среде. PostgreSQL, Render, CI и тесты не подключены.
